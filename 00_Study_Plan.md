# D.Pharm Part II — Pharmacotherapeutics ER-2020
## 3-Day Exam Preparation Pack

**Course:** ER20-24T — Pharmacotherapeutics  
**Theory:** 75 hours / 3 hours per week  
**Source:** PCI ER-2020 D.Pharm Part II syllabus.

### How to use this pack
With only 3 days, do not read every topic with equal depth.

- **Day 1:** Chapters 1–4 — foundations + cardiovascular + respiratory + endocrine
- **Day 2:** Chapters 5–8 — CNS + GI + haematology + infectious diseases
- **Day 3:** Chapters 9–12 — musculoskeletal + dermatology + psychiatry + ophthalmology/AMR/women's health + full revision

### Exam method
For every disease, memorize this sequence:

> **Definition → Etiopathogenesis → Clinical manifestations → Non-pharmacological management → Pharmacological management → Monitoring / counselling**

### Interactive syntax
- Try each question before opening the answer.
- Use the **Quick Recall** sections for rapid revision.
- Use the **Long-answer framework** to practise 5–10 mark answers.
- Drug examples are for exam learning; actual prescribing depends on patient-specific factors and current clinical guidance.

### Priority rule
If time is very limited, learn:
1. Definitions and classifications
2. Major clinical features
3. First-line / commonly used drug classes
4. Important adverse effects and counselling points
5. Key differences between similar diseases
6. Short notes and MCQs
